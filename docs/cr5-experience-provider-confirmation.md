This matrix carries forward the exact CR4 catalogue decisions. It does not
republish held Experiences or assert that any provider exists. `LEGAL
VERIFICATION REQUIRED` is used where the applicable Sri Lankan licensing,
insurance or regulated-practice requirement must be confirmed by qualified
human review.

## Sixty-one MINOR FIX dependencies

CR4's MINOR FIX label is not itself a supplier hold. Apply these evidence rules
when enriching those records:

| Missing/enrichment type | Confirmation class |
| --- | --- |
| Operator-controlled duration, start time, group size, equipment, participant limits, weather/season rules or cancellation | SUPPLIER CONFIRMATION |
| Temple, park, museum, rail, conservation or official venue access/hours | AUTHORITATIVE FACTUAL CONFIRMATION |
| Positioning, route priority, signature status or whether the proposition belongs in the launch portfolio | FOUNDER CONFIRMATION |
| Grammar, formulaic editorial phrasing, stable title presentation or non-factual layout copy | NO EXTERNAL CONFIRMATION |

No staging supplier, guide or application currently supplies evidence for the 16
QUESTIONABLE or seven held records. There are zero guide-to-Experience links,
zero pricing plans and zero supplier allocations. Every supplier-dependent fact
therefore remains unresolved until evidence is collected outside CR5.
