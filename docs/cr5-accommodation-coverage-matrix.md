# CR5 accommodation coverage matrix

This founder-facing matrix describes capability, not named procurement targets.
Every named property currently in staging is a `DEMO / SEED` record and must not
be treated as a contracted or verified hotel. Consequently, verified coverage is
zero across all 29 active destinations.

## Coverage principles

- A destination does not automatically need its own hotel. Short excursions may
  use a nearby overnight base when the resulting route is comfortable and clear
  in the proposal.
- P0 means required to accept a narrow set of controlled launch routes.
- P1 expands geographic and seasonal range after the P0 operating chain works.
- P2 is network depth or an excursion/en-route option, not a launch blocker.
- “Minimum” means distinct, verified choices where feasible; it is not permission
  to contract arbitrary properties or promise live availability.

## Controlled-launch accommodation portfolio

Do not try to fill all 29 rows before the first paid journey. The minimum useful
portfolio is a verified arrival base in Colombo; Cultural Triangle options based
around Sigiriya; Kandy; one tea-country base (Nuwara Eliya or Ella according to
the accepted route); one southern base (Galle with Mirissa access); and Yala.
For each base, prefer a primary and a backup in at least two stay categories.
Only sell routes that fit the actually contracted subset.
